# Дизайн-система

**Формула: Alfa как основа × чистота Plata × объём Drinkit.** Собственный визуальный актив один — исходный логотип
«Опоры». Всё остальное — открытая дизайн-система Альфа-Банка `@alfalab/core-components` (MIT,
[github.com/core-ds/core-components](https://github.com/core-ds/core-components)): компоненты, иконки и токены.
Экраны не копируют Альфа-Бизнес; логотип и фирменные знаки банка не используются.

## Логотип «Опоры»

Исходный знак из `main_logo.png` и его версии из истории проекта, без перерисовки (`miniapp/src/assets/brand/`):

| Файл | Где |
|---|---|
| `wordmark-graphite.webp` — объёмное «опора.» графит | Шапка клиентского кабинета |
| `wordmark-silver.webp` — то же, серебро (обесцвечено, без прежнего сине-фиолетового оттенка) | Рабочее место банка, тёмные карточки |
| `mark-graphite.webp`, `mark-silver.webp` — знак «O.» | Подвал |
| `hero-mark.webp` — объёмный «O.» из `main_logo.png`, нейтральное серебро, фон убран по яркости | 3D-объект тёмных поверхностей: hero, карточка компании, решение, кредит |

## Что взято из Alfa

| Слой | Пакет |
|---|---|
| Токены: цвета (`colors-bluetint`), тени `--shadow-*`, радиусы, отступы, системный шрифт | `core-components-vars` (только файлы с `:root`; `typography.css`/`mixins.css` — это PostCSS-миксины, их не подключаем) |
| Действия | `Button` (`accent` — главное действие, `primary`, `secondary`, `colors="inverted"` на тёмных поверхностях) |
| Ввод | `Input`, `Textarea`, `Select`, `RadioGroup` + `Tag` (цели), `RadioGroup` + `Radio`, `SegmentedControl` (фильтры банка) |
| Навигация | `Steps` (пять шагов), `Tabs` (карточка заявки в банке) |
| Данные | `Table` (реестр заявок), `Amount` (все суммы), `Status` (состояния и решения), `ProgressBar`, `CircularProgressBar` (готовность анкеты) |
| Сообщения | `Plate` (ошибки, предупреждения, запрос данных), `Tooltip` («Зачем банк спрашивает это?») |
| Типографика | `Typography.Title` / `TitleResponsive` |
| Иконки | `@alfalab/icons-glyph` внутри `IconView` (`SuperEllipse`) — цели, разделы, причины, рекомендации |

Бренд-шрифты Альфы (Styrene UI, Alfa Interface Sans) проприетарны и не входят в пакеты, поэтому используется
токен Alfa `--font-family-system` (системный шрифт), как и в самих компонентах.

## Plata: ясность

- Крупные уверенные заголовки (до 60–64 px, плотный трекинг), один главный смысл на экран.
- Чистые белые карточки на `bg-secondary`, щедрые отступы, скругления 24–32 px.
- Сильный CTA — один красный `accent` на экран, остальные действия вторичные.
- Тёмная «премиальная» поверхность только там, где нужен акцент: hero, рекомендованный продукт, ориентировочный
  расчёт, вердикт, кредит, лучший расчётный сценарий.

## Drinkit: объём

- 3D-объект — исходный «O.» из логотипа с мягкой тенью и красным свечением, лёгкая анимация «парения»
  (отключается при `prefers-reduced-motion`).
- Слои: стеклянные плашки с `backdrop-filter` поверх hero, карточка компании в лёгкой перспективе (наклон
  выравнивается при наведении), внутренний верхний блик и тонкая светлая кромка у тёмных поверхностей.
- Цвета только Alfa: красный, белый, чёрный, нейтральные серые. Синего, фиолетового и неона нет.

## Две оболочки

| | Клиентский кабинет | Рабочее место банка |
|---|---|---|
| Маршруты | `#/`, `#/credit/new`, `#/credit/applications/:id/:step` | `#/bank`, `#/bank/applications/:id` |
| Каркас | Светлая полупрозрачная шапка: логотип, компания, ссылка на банк | Тёмная боковая панель: логотип, навигация, DEMO-метка, роль аналитика |
| Тон | Эмоциональный, просторный, объясняющий | Плотный, рабочий: KPI-полоса, фильтры с количеством, поиск, таблица, моноширинные коды |
| Ключевые экраны | Старт, профиль компании, «Потребность» с живым расчётом, подбор, анкета, решение, «Как улучшить заявку», кредит | Реестр заявок, карточка: сводка, путь обработки, проверки, ML-риск с SHAP, скоринг, решение, события |

## Прозрачность анкеты

- Ошибка показывается у поля (`Input`/`Textarea` `error`) сразу при вводе: «Опишите цель подробнее: нужно не меньше
  20 символов, сейчас 13».
- Блок готовности разделяет обязательное и желательное: «Осталось 1 обязательное поле — описание цели, ещё 7
  символов» вместо голых «90%». Каждый пункт — ссылка, которая прокручивает к полю и ставит в него фокус.
- Полнота в процентах подписана: она учитывает желательные пункты и влияет на оценку, а отправить можно, когда
  заполнено всё обязательное.
- Кнопка «Отправить» не отключается молча: при попытке отправить неполную анкету подсвечиваются все проблемы.

## Ставка

Компонент `Rate`: итог и состав — две строки с явным разделителем в тексте:
**19,5% годовых** / 16% ключевая ставка + 3,5% маржа (+ надбавка за риск). Десятичная запятая везде, включая
текст решения.

## Адаптивность

Desktop — основной режим (1280–1440). Брейкпоинты: 1180 (одна колонка у анкеты, решения и потребности; KPI в
три колонки), 960 (hero в колонку, таблицы → карточки, боковая панель банка → верхняя полоса), 640 — телефон.

## Телефон (360–430 px)

Композиция и UX взяты из мобильной версии исходной «Опоры» ([archive](archive/opora-funding/mobile-interface.md)),
визуальный язык — текущий Alfa. Данные и действия те же, что на desktop: меняется только подача.

| Паттерн исходной «Опоры» | Как перенесён |
|---|---|
| Шапка в одну строку с круглыми кнопками 44 px | Логотип · компания (аватар, название, «сменить») · круглая кнопка банка |
| Подэкран: «‹» + заголовок, контент сразу | Шаги заявки: «‹» в кабинет, номер, ИНН и статус вместо хлебных крошек и большого заголовка |
| Главная: объект, затем крупные плитки действий | Компактный hero со знаком «O.» в углу; главный выбор — тёмная плитка, второй — белая; оба на первом экране |
| Строка-раскрытие «Условия программы ›» | `Reveal`: вторичное на телефоне свёрнуто — причины у неподходящих продуктов, риски и альтернативы, полнота анкеты, история |
| CTA формы внизу на всю ширину | `CtaBar`: «Подобрать финансирование» и «Отправить на рассмотрение» закреплены снизу с учётом safe-area; в конце формы — на своём месте |
| Карточка: крупная сумма, мета, статус, CTA снизу | Продукт, сценарий улучшения, заявка в банке; рекомендованный продукт — первым |
| Горизонтальные ленты | Пять шагов в hero и примеры потребности — лента с прокруткой |

- Шаги: «Шаг N из 5», название и пять сегментов; полный список Alfa `Steps` — по «Все шаги».
- Решение: вердикт и условия (сумма; срок и платёж рядом; ставка двумя строками), причины — список с разделителями,
  «Что дальше», объяснение — 4 строки и «Читать полностью», «Как улучшить заявку» — лучший сценарий выделен,
  сценарии — вертикальные карточки с полосой нагрузки.
- Банк: тёмная полоса в одну строку (иконки с доступными названиями), KPI в 2 колонки, фильтры — лента, поиск на всю
  ширину, заявки — карточки со скорингом, ML-риском и решением, вкладки 44 px.
- `useCompact()` (`max-width: 640px`) переключает только подачу; состояние, запросы и бизнес-логика общие.
- Без горизонтальной прокрутки, цели нажатия от 40–44 px; E2E проверяет это на 390 в Chromium и WebKit.

## Тесты разметки

Компоненты Alfa импортируют CSS и используют `matchMedia`; `scripts/static-render-setup.cjs` заглушает `.css`,
`.webp` и `matchMedia` для тестов в Node.
