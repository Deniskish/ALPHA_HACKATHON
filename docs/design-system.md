# Дизайн-система

Интерфейс «Опоры» построен на открытой дизайн-системе Альфа-Банка — пакетах `@alfalab/core-components` (MIT,
[github.com/core-ds/core-components](https://github.com/core-ds/core-components)). Название «Опора» сохраняется;
экраны не копируют Альфа-Бизнес пиксель в пиксель, логотип и товарные знаки банка не используются.

## Что взято из Alfa Design System

| Компонент | Где |
|---|---|
| `Button` (`accent` — красная основная, `secondary`, `outlined`) | Все действия |
| `Input`, `Textarea` | Потребность, анкета, ИНН, ручной ввод компании |
| `Select` | Срок, цель, форма компании |
| `RadioGroup` + `Tag` | Выбор цели финансирования |
| `RadioGroup` + `Radio` | Кредитная история |
| `Steps` | Индикатор пяти шагов |
| `Tabs` | Банковская карточка заявки |
| `Status` | Состояния заявки и решения |
| `Tooltip` | «Зачем банк спрашивает это?» |
| `ProgressBar` | Полнота анкеты |

Обязательные peer-пакеты: `core-components-config`, `core-components-stack-context`.

## Собственные компоненты

Там, где в системе нет готового решения под задачу: карточки продуктов с разложением ставки, панель «Что мы учли»,
таблица/карточки расчётных сценариев, чек-лист готовности по группам, таймлайн рассмотрения, путь обработки
APPLICATION RECEIVED → … → RESULT, карточки возможностей, блок объяснения. Они собраны из простых классов `op-*`
(`miniapp/src/credit/credit.css`) и общих примитивов в `ui.tsx` (`Section`, `Facts`, `ReasonList`, `SyntheticBadge`).

## Визуальный язык

- Одна светлая тема: белые поверхности на `#f3f4f5`, почти чёрный текст, акцент **`#ef3124`** только для главного
  действия, рекомендаций и ошибок. Тёмная тема прежней версии убрана, чтобы не расходиться с компонентами.
- Шрифт Manrope (OFL), скругления 12–20 px, мягкие тени.
- Цвет несёт смысл: зелёный — выполнено/одобрено, оранжевый — внимание/встречное, красный — отказ/риск, синий — инфо.
- Синтетические данные всегда помечены жёлтой плашкой «Синтетические демонстрационные данные».

## Адаптивность

| Ширина | Раскладка |
|---|---|
| ≥ 1100 px | Анкета и решение — основная колонка + боковая (готовность, история) |
| 900–1100 px (планшет) | Одна колонка, боковой блок над содержимым |
| ≤ 900 px | Банковская таблица → карточки, сценарии → карточки с подписями полей |
| ≤ 640 px (телефон, 390 px) | Поля в одну колонку, кнопки на всю ширину, «Шаг N из 5», шапка в две строки |

E2E проверяет отсутствие горизонтальной прокрутки на 1280 и 390 px в Chromium и WebKit.

## Тестирование SSR

Компоненты Alfa импортируют CSS и используют `matchMedia`; для тестов разметки в Node `scripts/static-render-setup.cjs`
заглушает `.css` и `matchMedia`.
