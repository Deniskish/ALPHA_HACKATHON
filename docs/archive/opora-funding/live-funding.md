# Автоматический каталог мер поддержки

Дополнено независимыми официальными источниками. Актуальная архитектура, ограничения, проверка и мониторинг описаны в [multi-source-funding.md](multi-source-funding.md). Ниже — исходная интеграция Минфина и общие настройки.

## Что подключено

Официальный портал Минфина «Электронный бюджет»: https://promote.budget.gov.ru/public/minfin/activity. Сервер загружает опубликованные отборы на субсидии, сохраняет ссылку на объявление, организатора, даты и известные категории получателей. Существующие шесть программ остаются в каталоге.

Проверка выполняется раз в 15 минут. Это периодическое обновление, не поток событий и не гарантия мгновенного появления новых мер. Первые 1 000 карточек обновляются каждый цикл; если активные отборы продолжаются, обход расширяется до 5 000. Отдельный сохранённый курсор постепенно обходит остальные страницы. Портал содержит и архив: его общее число записей нельзя выдавать за число действующих мер.

На локальной проверке 26 сентября 2026 года источник вернул 43 370 записей, из которых первый проход импортировал 990 незакрытых отборов. Каталог вместе с прежними программами содержит 996 записей. Числа меняются со временем. Это один большой официальный источник, не все меры поддержки России.

Нет публичного SLA или договора API: структура портала может измениться. При ошибке сохраняется последняя успешная копия; статус доступен через `/api/funding/live-status`. Неизвестные условия не становятся подтверждёнными. Общий бюджет субсидии не подставляется как сумма одному получателю.

## Профиль бизнеса

После добавления компании или проекта в приложении появляется поздравление, которое сохраняется на устройстве. Редактирование той же компании не создаёт повтор. В «Мой бизнес» есть удаление с подтверждением: очищаются профиль, параметры подбора, AI-контекст и поздравление. Черновики и избранное сохраняются, но старые черновики не становятся данными новой компании.

## Настройка сервера

Используется Node.js 22. Переменные:

| Переменная | Назначение |
| --- | --- |
| `FUNDING_SYNC` | `off` отключает фоновое обновление каталога; по умолчанию включено |
| `OPORA_FUNDING_DIR` | Постоянный каталог для `catalog.json` и данных официальных сайтов (`official-web/`); по умолчанию `miniapp/api-server/source-data/funding` |
| `GIGACHAT_AUTH_KEY`, `GIGACHAT_SCOPE`, `GIGACHAT_MODEL` | Серверный доступ к GigaChat |

`restart-api.cjs` сохраняет эти настройки PM2, не печатая секреты. Каталог данных не должен удаляться при деплое; текущий деплой через Git не удаляет этот игнорируемый каталог.

Для портала Минфина добавлен публичный промежуточный сертификат GlobalSign, отсутствующий в выдаваемой сервером цепочке. Доверие ограничено соединением с этим источником; проверка TLS не отключается.

## Проверка реализации

- Автотесты API покрывают импорт и нормализацию отборов, подробные условия, цитаты AI при извлечении, дубликаты, перезапуск и независимость источников. Внешние ответы GigaChat в тестах подменены контролируемыми ответами.
- Реальный источник: загрузка каталога и подробных условий проверена локально 26.09.2026.
- Прямая ссылка `?program=<id>` открывает нужную карточку после загрузки каталога; закрытая карточка не открывается повторно при обновлении.

Деплой дополнительно запускает `funding-catalog/smoke-check.cjs`: проверяет состояние мониторинга каталога и настоящий источник «Электронного бюджета», включая полноту подробных условий. Проверка ничего не изменяет и не обращается к пользовательским данным.
