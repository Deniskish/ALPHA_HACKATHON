# Клиент и не клиент банка

Первый экран предлагает демо-выбор: **«Я клиент Альфа-Банка»** или **«Я пока не клиент Альфа-Банка»**. Это не
авторизация: выбор хранится в `sessionStorage` (`session.ts`), реальных данных и входа в банк нет — об этом сказано
на экране и в подвале. Рассматривается только действующий бизнес.

## Клиент банка

1. «Вход в демо-кабинет клиента» — список синтетических компаний-клиентов (A–D) со сценарием и оборотами по счёту.
2. Кабинет показывает данные, которые банк «уже знает» (`Company.bankProfile`, синтетические): клиент с какой даты,
   средние обороты по счёту, продукты банка, маскированный счёт.
3. На подборе и в анкете финансы подставлены «по данным банка» (`FINANCE: OK`), источник отмечен.
4. Клиенту не нужно прикладывать бухгалтерскую отчётность, если финансы есть в данных банка.

Исключение для демонстрации: «Демо Агро» (C) недавно перевёл счёт и отчётности в данных нет — банк попросит показатели
и документ (NEEDS_INFO).

## Не клиент

1. Ввод ИНН (с проверкой контрольной суммы) → `GET /api/companies/:inn`: синтетический реестр, ранее сохранённая
   компания или необязательный реестровый поиск (DaData / индекс ФНС). Подсказки: `0005000050`, `0006000060`.
2. «Проверьте сведения о компании» — название, ИНН, дата регистрации и срок работы, ОКВЭД, регион; «Данные верны,
   продолжить». Компания `relationship: non_client`, `bankProfile: null`.
3. Если компании нет в источниках — ручная форма (название, форма, дата `ДД.ММ.ГГГГ`, ОКВЭД, регион).
4. На шаге «Потребность» — ключевые показатели (выручка, расходы, кредиты), чтобы подбор сразу учёл нагрузку.
5. В анкете финансовые показатели и **бухгалтерская отчётность обязательны** (`readiness.ts`): без данных банка
   цифры подтверждаются документом. Проверка финансов получает статус `DOCUMENT_BASED`.
6. Компания без реестровых данных дополнительно прикладывает выписку ЕГРЮЛ/ЕГРИП.

## Различия

| | Клиент | Не клиент |
|---|---|---|
| Вход | Выбор демо-компании | ИНН → подтверждение / ручной ввод |
| Профиль | Данные банка (синтетические) | Реестр (синтетический или необязательный внешний) |
| Финансы | Из данных банка | Ввод клиента + обязательная отчётность |
| Кредитная история | Mock БКИ | Mock БКИ (для новых компаний — «нет истории») |
| Решение и правила | Одинаковые | Одинаковые |

Заявленная клиентом кредитная история сверяется с БКИ: расхождение банк видит в причинах (`DECLARED_HISTORY_MISMATCH`).
