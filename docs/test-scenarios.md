## Негативные API-проверки

| Запрос | Ожидаемый ответ |
|---|---|
| `POST /api/applications` с `requestedAmount: -5` | 400 `VALIDATION_ERROR`, `details.field = requestedAmount` |
| `POST /api/applications/:id/submit` для неполной заявки | 422 `APPLICATION_INCOMPLETE`, `details.missing` |
| `POST /api/applications/:id/process` до отправки | 409 `INVALID_STATE` |
| `POST /api/applications/:id/accept` в DRAFT или REJECTED | 409 `INVALID_TRANSITION` |
| `POST /api/applications/:id/issue` до подписания или повторно | 409 `INVALID_TRANSITION` |
| `POST /api/applications/:id/payments` без выдачи / после погашения | 409 `INVALID_STATE` / `FINANCING_REPAID` |
| `GET /api/applications/:id/risk` до рассмотрения | 404 `RISK_NOT_READY` |
| `GET /api/applications/:id/improvements` до решения или при NEEDS_INFO | 404 `IMPROVEMENTS_NOT_READY` |
| `GET /api/applications/:id/explanation?kind=other` | 400 `VALIDATION_ERROR` |
| `POST /api/assistant/parse-need` с пустым текстом | 400 `VALIDATION_ERROR` |
| `PATCH /api/applications/:id` после решения / со старой `version` | 409 `APPLICATION_LOCKED` / `VERSION_CONFLICT` |
| Повторный `POST /process` | 200, `replayed: true`, новых событий нет |
| Повтор POST с тем же `Idempotency-Key` и телом / другим телом | Сохранённый ответ, `Idempotent-Replayed: true` / 422 `IDEMPOTENCY_KEY_REUSED` |
| Некорректный JSON или тело > 48 КБ | 400 `INVALID_INPUT` |
