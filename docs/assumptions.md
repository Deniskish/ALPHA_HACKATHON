# Допущения

| Допущение | Что это значит |
|---|---|
| **Скоринг синтетический** | Факторы, веса и пороги `ScoringEngine` придуманы для демонстрации объяснимой оценки. Они не откалиброваны на данных и не предсказывают дефолт. |
| **Логика решения синтетическая** | Правила `CreditDecisionEngine` (стоп-факторы, пороги 60/75, лимит платежа 50% прибыли, долговая ёмкость 50% выручки, надбавка +2 п.п.) — демонстрационные, а не кредитная политика банка. |
| **Кредитные продукты синтетические** | «Оборотный кредит», «Инвестиционный кредит», «Экспресс-кредит» и их суммы, сроки и ставки вымышлены и не являются предложениями Альфа-Банка или другого банка. |
| **Интеграции ФНС/БКИ замоканы** | Ответы ФНС, бюро кредитных историй и финансовых источников возвращают локальные провайдеры из синтетического набора; сеть не используется. |
| **Подписание смоделировано** | «Подписать договор (симуляция)» меняет состояние на COMPLETED; электронная подпись и договор не создаются. |
| **Выдача денег не выполняется** | Ни на одном шаге не происходит перевода средств и не создаётся кредитный договор. |
| **Демо-данные синтетические** | Компании «Демо …» вымышлены; их ИНН проходят проверку контрольной суммы, но используют неприсвоенный код региона `00`. Реальные персональные данные не используются. |
| **Это не банковская скоринговая система** | Решение демонстрирует процесс и связность клиентской и банковской сторон; использовать его для реальных решений нельзя. |

## Дополнительные допущения MVP

- **Один демо-клиент.** Авторизации нет; переключатель «Клиент / Банковская сторона» — демонстрационный, клиент
  видит все заявки стенда.
- **Документы — метаданные.** На сервер передаются тип, имя, размер и число извлечённых символов; подлинность и
  содержание документов не проверяются.
- **Заявленные финансы** учитываются, только если во внешних источниках их нет и приложена бухгалтерская отчётность.
- **Компания без реестровых данных** проходит проверку ФНС только с выпиской из ЕГРЮЛ/ЕГРИП; отсутствие кредитной
  истории оценивается нейтрально.
- **Возраст бизнеса** считается от даты регистрации до текущей даты сервера.
- **Одна попытка — одна оценка.** После NEEDS_INFO и повторной отправки создаются новые проверки, оценка и решение;
  прежние сохраняются в истории.
- **Синхронная обработка.** Mock-источники отвечают мгновенно, поэтому все этапы выполняются в одной транзакции;
  клиентский таймлайн проигрывает уже записанные этапы.
- **Лимит запросов** — 300 в минуту на клиента; в Docker все запросы приходят от nginx и делят этот лимит.
